# Report Review

Review the submitted report and evidence as an independent session. Do not trust prose, hidden reasoning, or a claimed execution status.

Check:

- every material claim has evidence;
- evidence is registered and digest-valid;
- required validation contracts have matching results;
- assumptions are visible and materially justified;
- code and environment can be reproduced;
- figures agree with the underlying data;
- error and sensitivity analysis address the stated risks;
- limitations are not hidden in confident language.

Return one verdict. For revision, identify the target stage, defect class, affected claims, required evidence, and acceptance check. `approve` is valid only when the Harness publication gate can independently verify the evidence.
