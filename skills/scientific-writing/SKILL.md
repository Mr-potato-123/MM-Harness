# Scientific Writing

Organize the report around the question and evidence: problem statement, data and provenance, assumptions, notation, model formulation, solution method, validation, results, sensitivity/uncertainty, limitations, and conclusion. Define symbols before use and keep units and terminology consistent.

Connect every table and figure to a question in the text and embed only files
that actually exist. State what was computed, under which assumptions, and what
the result does and does not establish. Distinguish method description from
results and association from causation. Quantitative conclusions must match
registered outputs exactly, including units and rounding.

Draft the abstract after the result sections so it can name each question's
method and verified result without placeholders. Use concise technical prose in
the user's language. Preserve citations and claim scope across Markdown and
LaTeX. Do not introduce new results during writing; expose unresolved gaps
rather than smoothing them over.
