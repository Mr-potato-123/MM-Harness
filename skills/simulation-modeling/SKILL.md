# Simulation Modeling

Define state, events or update equations, time semantics, parameters, initial conditions, random inputs, outputs, and termination. Separate calibrated quantities from assumptions and scenarios. Select Monte Carlo, discrete-event, agent-based, or continuous dynamics because its mechanics match the question, not because it is elaborate.

Verify the simulator on degenerate and analytically solvable cases, conservation or balance laws, event ordering, step-size convergence, and invariant bounds. Fix or record seeds while using enough independent replications. Separate warm-up, run length, and sampling error.

Report distributions and confidence intervals, not a single stochastic trajectory. Test parameter and structural sensitivity. Calibration to one dataset is not validation; compare held-out behavior or independent aggregate properties where available.
