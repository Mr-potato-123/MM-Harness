# Report Rendering

Rendering is a pure projection of reviewed content. Preserve headings, tables,
figures, units, citations, limitations, and artifact links. Do not add new
analysis during layout.

Use local rendering tools only. Validate output paths stay inside the workspace
or immutable artifact store, and retain the source and digest for audit.
