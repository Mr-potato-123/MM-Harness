# Visualization

A figure is an evidence artifact, not decoration. Generate it from immutable
inputs with a declared transformation and deterministic seed/style.

- Select a chart that answers the question; do not imply unsupported trends.
- Include units, uncertainty/error bars when available, readable labels, and a
  caption that names the source artifact and transformation.
- Save the source data/plot code alongside the image. Check dimensions, color
  contrast, and that the image is legible in the final report.
- If no verified data supports a figure, omit it rather than creating a
  conceptual plot that looks empirical.
