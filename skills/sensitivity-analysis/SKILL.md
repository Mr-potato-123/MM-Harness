# Sensitivity Analysis

Identify inputs whose uncertainty or policy choice could change the answer. Define defensible ranges and joint dependencies from evidence; do not vary arbitrary percentages without explaining them. Use local one-at-a-time checks only for near-linear screening, and global or scenario methods when interactions matter.

Track output changes, rank reversals, constraint violations, threshold crossings, and qualitative regime changes. Include structural sensitivity to alternative model forms, preprocessing, boundary conditions, and objective weights—not just fitted parameters.

Return stable conclusions, fragile conclusions, influential assumptions, tested ranges, and untested risks. A result is robust only within the stated perturbation space.
