# Claim Evidence

For every material claim, record the claim text, evidence artifact IDs/digests,
the relevant page/row/metric or code output, and a confidence/limitation note.

- Distinguish observed, computed, inferred, and proposed statements.
- A claim supported only by a model narrative is unverified; require execution
  artifacts and validation results where computation is involved.
- Keep citations and evidence links stable across revisions. Never cite a
  mutable workspace path without its immutable artifact digest.
- The final Markdown and TeX documents must express the same approved claims;
  publication formatting cannot strengthen evidence.
