# Publication Verification

Verify rather than rewrite. Check that every required question has a corresponding accepted section, symbols are defined, assumptions are justified, key numbers agree with immutable result artifacts, citations resolve, limitations remain visible, and Markdown/LaTeX express the same claims.

Detect placeholders, internal workflow leakage, missing or duplicate sections, broken figure paths, uncited figures, captions inconsistent with data, unexplained equations, stale outputs, and references without source records. Compile with the authorized local tool when available and treat syntax, path, or missing-package failure as a failed gate until resolved or explicitly classified as unavailable infrastructure.

After compilation, inspect page count and dimensions and, when visual inspection is available, review every rendered page for clipping, overlap, blank pages, broken glyphs, overflowing tables/equations, misplaced floats, and damaged template elements. Return PASS, FAIL, or INCONCLUSIVE with evidence and the narrowest responsible revision stage. Never invent a replacement number to fix inconsistency.
