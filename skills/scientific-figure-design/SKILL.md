# Scientific Figure Design

Classify each proposed figure as data evidence or method explanation. Data figures must be generated from registered source tables and code; method diagrams must be derived from the accepted model. Never use simulated template data as if it were the task result.

Choose an encoding appropriate to the analytical question and keep one main message per panel. Prefer vector PDF/SVG where the publication path supports it, plus a high-resolution raster only when needed. Use consistent typography, color semantics, units, uncertainty, panel labels, legends, and accessible contrast. Keep large titles out of the plot when the paper supplies a caption.

Save the plotting data or transformation, source code, output digest, and a short machine-readable synopsis of the values/trends the figure actually contains. Inspect the rendered artifact for clipping, overlap, missing glyphs, misleading axes, excessive density, and caption mismatch before publication.
