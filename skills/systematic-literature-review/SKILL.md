# Systematic Literature Review

Define the research question, databases or local collections, date window, query terms, inclusion/exclusion criteria, deduplication rule, target count, and stopping condition before screening. Preserve a search ledger so the result can be reproduced.

Extract the same fields from every included work: identifier, question, data, method, baseline, evaluation design, findings, uncertainty, limitations, and relevance. Do not infer a paper's result from its title or search snippet. Separate unavailable full text from negative evidence.

Synthesize across papers rather than listing them. Identify recurring themes, agreements, disagreements, methodological incompatibilities, evidence quality, and unresolved gaps. Avoid vote counting when studies have different endpoints or data regimes. Use one stable citation style and retain source identifiers. State coverage limitations and never fabricate bibliographic metadata.
